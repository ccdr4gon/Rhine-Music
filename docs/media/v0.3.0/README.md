# v0.3.0 Windows 客户端截图

`native-night-library.png` 来自 2026-09-30 在 Windows 11 x64 上实际安装的 Tauri + Rust release 客户端，保留系统标题栏以表明独立窗口。

测试曲库包含两个文件夹、三段用 FFmpeg 自行生成的低音量正弦 MP3；标题、歌手和年份均为测试标签。封面使用既有 `public/demo-covers/` 演示图片。不包含私人歌曲、曲库路径、配置或索引；生成音频与临时数据不随源码或安装包分发。

截图只用于展示这一台设备上的界面与原生窗口，不证明全部格式播放、跨设备帧率或像素级一致性。其他 `v0.2.0` 图片属于历史浏览器版本，不能作为客户端验收证据。

`native-skin-detail.png` 和 `native-skin-portrait.png` 来自追加皮肤功能后的实际 Windows 安装版，分别为横屏和 640×900 窗口。媒体来源为 `media_fixture` 测试程序，使用合成的 5.064 秒 MP3，蓝色纯色 PNG 是专用测试封面；播放器名称、曲名、歌手和专辑均为合成字段。图片不展示真实网易云、Chrome 或其他个人来源。截图时客户端已通过实际暂停、切歌、进度跳转、最小化恢复及多次自然循环验证，仍不代表所有品牌或版本的播放器均已验收。
